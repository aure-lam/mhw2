# 🧪 Homework 2 - Web Programming



---

## 📄 Descrizione del progetto

Questo progetto rappresenta il secondo mini-homework (MHW2) del corso di **Programmazione Web**, incentrato sull'integrazione di **JavaScript** in una pagina web esistente realizzata nell'MHW1.

La pagina è una simulazione promozionale per il brand _Air Up - Reset_, con una struttura responsive e interattiva.

---

## ✅ Requisiti soddisfatti

Sono stati implementati i seguenti comportamenti dinamici richiesti:

- ✅ Uso di `addEventListener()` per la gestione degli eventi utente.
- ✅ Uso di `document.createElement()` per la creazione dinamica di elementi HTML.
- ✅ Modifica dinamica dell’attributo `src` di un’immagine.
- ✅ Manipolazione dinamica delle classi CSS con `classList`.
- ✅ Mostrare e nascondere dinamicamente parti della pagina tramite classi CSS.
- ✅ Utilizzo di attributi `data-*` per contenere dati aggiuntivi.

---

## 🔧 Funzionalità interattive

- **"Leggi di più"**: in una delle sezioni informative, è presente un bottone che, se cliccato, mostra dinamicamente un paragrafo extra con dettagli nascosti (contenuti nell’attributo `data-extra`) e rimuove il bottone stesso.
- **Cambio aroma**: nella sezione "Scegli il tuo aroma", cliccando sulle miniature degli aromi si aggiorna l’immagine principale, cambiando dinamicamente il contenuto tramite l’attributo `data-src`.
